Inline math uses KaTeX: $e^{i\pi} + 1 = 0$.

Display math uses a pair of dollar signs:

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

## Interactive visualizations

Add a fenced `plotly` block with JSON data and layout to create an interactive Plotly chart:

```plotly
{
  "data": [{
    "x": [1, 2, 3, 4, 5],
    "y": [1, 4, 2, 5, 3],
    "type": "scatter",
    "mode": "lines+markers",
    "name": "Example"
  }],
  "layout": {
    "title": "An interactive chart",
    "xaxis": { "title": "x" },
    "yaxis": { "title": "y" }
  }
}
```
